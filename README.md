# Unity Intro Workshop: starter project

Starter project for a hands-on introduction to Unity. We build a small 3D game: an island, a character that walks and jumps, and coins to collect.

## Requirements

- Unity Editor **6000.6.9f1** (the version must match exactly)
- Unity Hub

## How to open

1. Download the project: **Code > Download ZIP**, then unzip it.
2. In Unity Hub, click **Add > Add project from disk** and pick the unzipped folder (the one that contains `Assets`).
3. Open the project. The first import takes 5 to 15 minutes.
4. Open `Assets/Scenes/GameScene` and press Play. You will see only sky: that is correct.

## If you fall behind

`Assets/Checkpoints` holds one scene per level plus the finished scripts as `.txt` files. See `Assets/Checkpoints/README.txt`.
